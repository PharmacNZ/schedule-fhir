Extension: Medication Unit of Measure

Official URL: https://fhir-ig.digital.health.nz/pharmac-schedules/StructureDefinition/medication-unit-of-measure Version: 1.0.1
Draft as of 2026-04-24 Computable Name: MedicationUnitOfMeasure

The unit of measure used for this medication. For example, 'tab' (tablet), 'cap' (capsule), 'ml' (milliliter), 'sach' (sachet).

Context of Use

    This extension may be used on the following element(s)

    • Element ID: Medication

Usage info

Usages:

  • Use this Extension: PHARMAC Medication
  • Examples for this Extension: Bundle/SearchSet-Bundle-All-Medications, Bundle/SearchSet-Bundle-Clexane-Pricing, Medication/Medication-Clexane-100mg-1ml-Syringe, Medication/Medication-Fortisip-Multi-Fibre-Chocolate and Medication/Medication-Nutrison-800-Complete-Multi-Fibre
